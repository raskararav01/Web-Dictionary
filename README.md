# 📚 Multilingual Web Dictionary App

A responsive, feature-rich web dictionary application that allows users to search for English word definitions, pronunciations, and automatically translates meanings into **Hindi** or **Marathi** in real-time.

---

## 🌟 Key Features
- 🔍 **Real-time Word Lookup:** Fetches definitions, parts of speech, and phonetics using the free Dictionary API.
- 🌐 **Multilingual Translation:** Translates English definitions into **Hindi** or **Marathi** on the fly via the MyMemory Translation API.
- 🔊 **Audio Pronunciation:** Playable audio pronunciation button for searched words.
- 📱 **Clean Responsive UI:** Centered container design built with custom CSS and Poppins typography.

---

## 🛠️ Tech Stack & APIs Used
* **Frontend:** HTML5, CSS3, JavaScript (ES6 Promises / Fetch API)
* **Fonts & Icons:** Google Fonts (*Poppins*), Font Awesome icons
* **APIs:**
  * [Free Dictionary API](https://dictionaryapi.dev/) for word definitions and audio.
  * [MyMemory Translation API](https://mymemory.translated.net/) for language translation.
